# Repository future

Decision date: 2026-10-07

PROJECT-PREVIEWS is not an implementation authority and is not a main engineering root.

Its purpose is a public, sanitized projection of selected private projects. It may remain separate while that visibility boundary is useful.

Long-term retirement is allowed if an equally safe public-publication mechanism replaces it. No private source, case material, credentials or production data may be introduced merely to reduce repository count.
