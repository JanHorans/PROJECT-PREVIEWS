# PROJECT PREVIEWS

Technical read-only previews of three independent internal projects.

This repository is intentionally documentation-only. It contains no production secrets, live operational data, case evidence, credentials, private keys, or source code from the private development repositories.

## Projects

### [FORGE](FORGE/README.md)
Portable, local-first neuro-symbolic digital-forensics workstation.

Focus: heterogeneous evidence ingestion, deterministic normalization, provenance, timeline, entities/relations, findings/hypotheses, local AI-assisted analysis, report and protocol-draft generation.

### [REPORT BUILDER](REPORT-BUILDER/README.md)
Portable Windows analytical helper for structured data, timelines, IP/OSINT enrichment and traceable exports.

Focus: fast analyst workflow over tabular or pasted data without requiring the full FORGE case platform.

### [ATLAS](ATLAS/README.md)
Self-hosted internal communication and operational coordination platform.

Focus: Matrix/Element communication plus portal, command, operational map, location-oriented dashboard and team coordination.

## Why this repository exists

The active development repositories are private. This public preview provides enough technical context to understand the architecture, current maturity and direction of each project without exposing implementation details that should remain private.

Each project folder contains:

- a technical overview;
- a simplified structure map;
- a roadmap/current-state summary;
- notes on the design decisions worth reviewing.
