# REPORT BUILDER — Direction Preview

The private repository currently uses its v0.3.0 README and stable release snapshot as the authoritative baseline rather than maintaining a separate formal ROADMAP.md.

## Current baseline

- Timeline module
- deterministic overlap/conflict analysis
- common desktop tabular imports
- standalone HTML reporting
- JSON project persistence
- IP extraction and public-IP enrichment
- provenance-aware CSV/JSON/HTML exports

## Likely development direction

- additional focused data connectors;
- broader OSINT modules;
- richer visualization and analytical templates;
- continued portable packaging;
- optional import/export bridge to FORGE while remaining independently useful.

The project intentionally avoids pretending that planned modules already exist.
