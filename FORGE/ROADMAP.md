## Current direction

### Evidence-source expansion
Next source families include mail/message files and headers, saved HTML/web artifacts, browser exports and generic structured logs.

### Specialist agent network
Bounded specialist agents are planned for timeline, remote access, browser/web, mail, phone, IOC/infrastructure, identity, contradiction, OSINT and reporting.

### Local learning
The design separates isolated case memory from validated local know-how and developer-controlled upstream knowledge packs. Silent cross-case learning is deliberately avoided.

### Advanced neuro-symbolic analysis
Longer-term work includes multi-agent orchestration, contradiction graphs, uncertainty handling, temporal reasoning and evidence-aware OSINT.

### Distribution
The target is a portable external-drive distribution that can run on sufficiently capable Windows analyst hardware with no required cloud dependency for core case analysis.

## Design rule

The maturity of FORGE should grow primarily by widening real evidence coverage and maintaining trustworthy provenance — not simply by adding more UI or more autonomous AI behavior.
